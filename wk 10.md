# Face Recognition Attendance System

1. Project Overview

The "Face Recognition Attendance System" is a Python-based application that uses computer vision to detect faces through a webcam and attempt to recognize registered students. The system is designed to simplify attendance recording by storing attendance information in CSV files.

The project uses OpenCV for face detection and LBPH (Local Binary Patterns Histograms) for face recognition. Pandas is used to manage attendance records.

2. Problem Statement

Traditional attendance methods require manual recording, which can consume time and introduce errors. This project explores an automated approach that uses face detection and recognition to assist with student attendance management.

3. Objectives

- Detect faces using a webcam.
- Attempt to recognize registered students.
- Record attendance details automatically.
- Store attendance data in CSV format.
- Record student ID, name, date, and time.
- Explore handling unknown faces and multiple faces.
- Test the application under different operating conditions.

6. Working Principle

The system follows these steps:

1. The webcam captures a video stream.
2. OpenCV converts video frames into grayscale images.
3. Haar Cascade detects faces in the captured frames.
4. The LBPH recognizer attempts to match detected faces against the trained model.
5. The application checks the recognition result against its confidence threshold.
6. The student ID is matched with the student details file when a student is identified.
7. Attendance information is recorded with the date and time.
8. The attendance records are saved as CSV files.

## 10. Installation and Execution

### Prerequisites

- Python installed on the system.
- A webcam.
- Required Python packages.
- The project files and Haar Cascade XML file.

### Install dependencies

Open a terminal in the project directory and install compatible versions of the required dependencies.

```bash
python -m pip install opencv-contrib-python numpy pandas pillow matplotlib yagmail
```

**Note:** This project uses an older codebase. Dependency compatibility may vary with the installed Python version. The `opencv-contrib-python` package is required for the `cv2.face` LBPH recognizer.

### Test face detection

```bash
python -c "import check_camera; check_camera.camer()"
```

The webcam should open and display detected faces. Press `q` to close the window.

### Run attendance recognition

```bash
python -c "import Recognize; Recognize.recognize_attendence()"
```

The attendance window should open. Press `q` to exit and allow the program to save its attendance CSV file.

**Important:** Recognition depends on a correctly trained model and matching student data. The current model has not consistently identified the test face, so retraining and validation are still required.

## 11. Limitations

- Recognition accuracy depends on the quality of training images.
- Lighting, camera quality, face angle, and distance can affect results.
- The existing recognition model requires further validation.
- CSV files are suitable for a prototype but are not a substitute for a secure database.
- Face recognition alone cannot guarantee protection against impersonation.
- The project does not currently provide a fully verified faculty login, attendance approval workflow, or secure anti-spoofing mechanism.
